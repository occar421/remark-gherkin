# AST Explorer Demo

Markdown with Gherkin AST Explorer inspired by [AST Explorer](https://astexplorer.net/).
It provides a live preview of the Gherkin AST using `remark-gherkin`.

## Use

This is a web application. You can access the hosted version (if available) or run it locally.

To run locally:

```bash
vp dev
```

## Features

- **Gherkin Editor**: Syntax highlighting with Monaco Editor.
- **AST Tree View**: Interactive and collapsible JSON tree representation of the AST.
- **Real-time Updates**: AST updates as you type.

## Development

```bash
vp install
vp test
vp dev
vp build
```
